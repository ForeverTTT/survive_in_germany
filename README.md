# 🚆 德区留子生存模拟器 (German Student Survival Simulator)


这是一个基于 AI 驱动的沉浸式文字冒险游戏。在这里，你不仅是在玩一个游戏，而是在重新经历（或者提前预演）那段充满德铁延误、外管局噩梦和硬面包力量的留德岁月。

---

## 🛠️ 紧急落地指南 (快速开始)

### 1. 登机准备 (环境安装)
你需要首先打开命令行, Node.js 环境。在终端执行：
```bash
npm install
```

### 2. 正式起飞 (启动游戏)
为了保证你的存档能**物理存储**在硬盘上（而不是风一吹就散的浏览器缓存），请使用合并指令：
```bash
npm run all
```
运行成功后，你会看到类似下面的输出：
```
[0] > node server.js
[1] > vite
[0] ✅ Save server running at http://localhost:3001
[1]   VITE v6.4.1  ready in 510 ms
[1]   ➜  Local:   http://localhost:3000/
[1]   ➜  Network: http://192.168.x.x:3000/
```
然后打开浏览器访问 `http://localhost:3000/` 或者提供的其他网址就可以开始游戏了！

## 🔍 你会在这里遇到什么？

留德生活不仅是学术，更多是琐碎而真实的困境：

*   **⚠️ 突发大事件 (Crisis Events)**：每隔几关，你会遇到不可避开的"德式考验"。可能是**全城交通大罢工**让你错过考试，也可能是**突如其来的 500 欧暖气补缴单 (Nachzahlung)** 让你的账户瞬间归零。
*   **🏠 房东与合同迷雾**：你以为签完 Mietvertrag 就万事大吉？现实是——房东可能突然"忘记"退押金（Kaution），也可能把你踢进一场关于 **Nebenkosten** 的口水仗：水电、暖气、垃圾处理费，账单像雪一样落下来。
*   **📺 Rundfunkbeitrag（电视费）追魂**：某天，你打开信箱，看到那封熟悉的"催缴通知"。你明明不开电视，却依然要交——在德国，这不是选择题，是必答题。你可以申诉、补材料、写信解释，但每一步都在消耗 Sanity。
*   **📮 信箱里不止有信，还有命运**：它可能装着外管局的补材料通知、保险的补缴提醒、或一张"你欠费了"的黄纸。错过一次，就可能让后续所有流程连锁崩坏。
*   **🎭 沉浸式社交**：你会遇到严厉但可能有内推机会的 **Schmidt 教授**，或者是带你融入 WG 生活的 **Clara**。记住，在德国，人脉（Vitamin B）有时比绩点更重要。

## 💡 留德生存Tips

为了让你能顺利活过第一学期，这里有几条刻在老留子 DNA 里的温馨提示：

1.  **信箱是你的"第二生命"**：在德国，任何重要的通知（特别是罚单和账单）都会通过纸质信件寄送。如果你连续一周不看信箱，可能会面临居留失效或信用受损。
2.  **垃圾分类是这里的"宗教"**：如果分错了垃圾，你可能会收到邻居精心手写的"爱心小纸条"。学会区分 Bio, Paper 和 Restmüll 是融入的第一步。
3.  **周日是"寂静之日" (Ruhezeit)**：周日超市**全部关门**！同时，请不要在这一天洗衣服或吸尘，否则你的 Hausmeister 可能会出现在你的门口。
4.  **Pfand 就是硬通货**：看到瓶子上的循环标志了吗？那不是垃圾，那是 0.25 欧。攒够一袋子就能在下周一换一顿 Mensa 饱餐。
5.  **Termin 是一种信仰**：办任何事都要预约。如果你试图在没有 Termin 的情况下闯入外管局，你将见识到德国官僚主义最冷酷的一面。

## ✨ 德味精髓

*   **📬 德式信箱系统**：在德国，信箱是灵魂的居所。你会收到外管局的最后通牒，或是室友的垃圾分类警告。
*   **🤝 社交圈 (Social Circle)**：去讨好严厉的 Schmidt 教授，或者向总能搞到兼职的 L 学长求助。好感度真的能救命。
*   **📓 留德日记**：真实记录你的心情。每一篇日记都会以 `.txt` 格式物理保存在你的 `saves/diaries` 文件夹中，多年以后也是一份回忆。
*   **🖼️ 记忆相册**：AI 会根据你的遭遇实时生成剧照。那些雪中晚点的列车、深夜的 Mensa，都会被永久收藏。
*   **☢️ 物理重置**：如果你觉得这辈子彻底玩砸了，设置里有一个"彻底重置"按钮。它会物理抹除磁盘上的一切存档，给你一次真正的重生机会。(不像现实中，被退学后该大类专业在全德范围内都不能读了)
