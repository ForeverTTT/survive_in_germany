# 德区留子生存模拟器 - 存档系统说明

## 📁 目录结构

```
saves/
├── progress/          # 游戏进度文件
│   ├── save.json     # 主存档（包含所有数据）
│   ├── achievements.json  # 成就
│   └── settings.json      # 设置
├── diaries/          # 日记本（.txt 文本文件）
│   ├── diary_1234567890_xxxxx.txt
│   └── ...
├── mailbox/          # 信箱（.json 文件）
│   ├── letter_1234567890_xxxxx.json
│   └── ...
└── album/            # 记忆相册（.json 文件）
    ├── img_1234567890.json
    └── ...
```

## ✨ 功能特性

### 🎮 自动同步
- 游戏会自动将所有数据同步到磁盘
- 每次保存游戏时，数据会写入对应的文件夹
- 支持双向同步：磁盘修改会同步到游戏

### 📖 日记本 (saves/diaries/)
- 每篇日记保存为独立的 `.txt` 文本文件
- 文件名格式：`diary_<timestamp>_<id>.txt`
- **可以直接在记事本中编辑日记内容！**
- 格式：
  ```
  Date: 2026/1/23 12:00:00
  Mood: happy
  Chapter: 1, Level: 5
  Location: 法兰克福机场

  Content:
  这是日记内容...
  ```

### 📬 信箱 (saves/mailbox/)
- 每封信保存为独立的 `.json` 文件
- 文件名格式：`<letter_id>.json`
- 包含信件标题、发送者、内容、时间戳等信息
- 可手动删除文件以删除信件

### 📸 记忆相册 (saves/album/)
- 每张照片的元数据保存为独立的 `.json` 文件
- 文件名格式：`<image_id>.json`
- 包含：
  - `url`: 图片路径
  - `title`: 照片标题
  - `chapter` / `level`: 所属章节关卡
  - `timestamp`: 时间戳
- 可手动删除文件以删除照片

## 🔄 数据同步规则

1. **游戏 → 磁盘**
   - 每次自动保存时，数据会同步到磁盘
   - 删除游戏内的条目，磁盘文件也会被删除

2. **磁盘 → 游戏**
   - 游戏启动时会读取磁盘文件
   - **日记本**：以磁盘 `.txt` 文件为准
   - **邮箱**：以磁盘 `.json` 文件为准
   - **相册**：以磁盘 `.json` 文件为准

3. **优先级**
   - 日记本：物理文件 > 游戏内存
   - 其他数据：较新的时间戳优先

## ⚠️ 注意事项

1. **编辑日记**
   - 可以在任何文本编辑器中编辑 `.txt` 文件
   - 修改后重新加载游戏即可看到变化
   - 请保持文件格式不变

2. **删除数据**
   - 直接删除文件夹中的文件即可
   - 重新加载游戏后，数据会同步

3. **备份**
   - 建议定期备份整个 `saves/` 文件夹
   - 可以将整个文件夹复制到其他地方作为备份

4. **重置功能**
   - 游戏内"彻底重置"会清空所有存档
   - 但**日记本**会被保留
   - 相册、邮箱、游戏进度会被清除

## 🛠️ 技术说明

- 服务器运行在 `http://localhost:3001`
- 使用 Node.js 本地服务器进行文件同步
- 支持跨域 CORS，可从浏览器访问
- API 端点：
  - `POST /api/save` - 保存数据
  - `GET /api/load` - 加载数据
  - `POST /api/reset` - 重置数据

## 💡 使用建议

1. **写日记**：在游戏内写完日记后，可以在 `saves/diaries/` 中找到对应的 `.txt` 文件进行二次编辑和润色

2. **管理相册**：如果相册太满，可以直接删除 `saves/album/` 中不需要的照片文件

3. **清理信箱**：可以批量删除 `saves/mailbox/` 中的旧信件文件

4. **备份存档**：复制整个 `saves/` 文件夹即可完整备份所有游戏数据
